# Yazan paid AI staged mode
Default mode is unchanged. Do not enable or purchase before integration testing and adult account approval. The paid OpenAI path uses one server on 30s, gpt-6-luna, UTC monthly buckets of $4.00 PDF and $1.00 chat, and conservative durable pre-reservations (timeouts are not refunded). Requires a persistent disk mounted at /var/data and YAZAN_BUDGET_DB=/var/data/yazan-budget.sqlite. No other clients may use this API key. The provider's actual bill, token count pricing, pricing changes and external calls are not guaranteed by the local ledger. Staff PDFs must not contain children's personal data. Player AI remains disabled unless safety measures (age-appropriate controls, privacy/data retention, moderation, reporting) are reviewed. See https://developers.openai.com/api/docs/guides/safety-checks/under-18-api-guidance. Existing local guide stays available. Set YAZAN_PAID_AI_MODE=openai only after tests; OPENAI_API_KEY is server-only. YAZAN_ADULT_ADMIN_APPROVED, YAZAN_STAFF_PDF_APPROVED and YAZAN_PLAYER_AI_SAFETY_READY are separate review gates, not proof of compliance. Never expose shared secret or key. Render disk costs are separate. No real paid request tested yet.
